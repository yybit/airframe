AirFrame
English GitHub

一个原生远程桌面
支持 VNC、RDP 和 SPICE。

用 Rust 打造的轻量级 GPU 加速远程桌面客户端。 统一管理所有机器的连接、输入与剪贴板，无需为每种协议各装一个客户端。

版本 0.1.2 Apache-2.0 许可证 macOS · Windows · Linux
下载 macOS 版通用二进制（Apple Silicon + Intel）· macOS 13+ 下载 Windows 版x64 · .msi 安装包 Linuxx64 · AppImage

Releases 页另有 .zip、.deb / .rpm / .tar.gz 及 aarch64 版本—— 也可以从源码构建：cargo install --path apps/airframe。

特性

远程会话需要的一切

一个小而快的原生应用，不是套着壳的 Electron。

三种协议，一个客户端

VNC、RDP、SPICE。新建连接时选协议，端口自动填好默认值。

原生 GPU 渲染

基于 egui/wgpu。秒级启动、内存占用低，在 Linux (X11/Wayland)、macOS 和 Windows 上原生运行。

连接井井有条

分组、即时搜索、标签页，vnc:// 链接一键导入。

剪贴板与文本输入

剪贴板文本与远程主机同步；另有发送文本窗口，绕过键盘映射直接输入，适合没有剪贴板的控制台。

键盘布局无关

按键按物理位置转换，本机的 Dvorak、AZERTY 等布局不会泄漏进远程会话。

密码默认不落盘

密码只保存在内存中，除非显式勾选“记住密码”。

协议

你的机器说什么，它就说什么

每个后端都是成熟协议库之上的轻量适配层，统一挂在协议无关的会话契约之下。

VNC

RFB / VNC

默认端口 5900 · vnc://

Raw、CopyRect、Hextile、ZRLE 帧缓冲，全部在 UI 线程之外解码。

RDP

远程桌面

默认端口 3389 · rdp://

自动安全协商、压缩传输，远程桌面分辨率跟随你的视口。

SPICE

SPICE

默认端口 5930 · spice://

为虚拟机提供显示与输入通道，直接由会话契约驱动。

会话体验

连上之后，处处顺手

悬浮工具栏、全屏、适应窗口 / 1:1 / 拉伸三种缩放、只读模式——而且没有任何全局快捷键：每个按键都送给远程，Ctrl+W 能退出远程的编辑器，F11 能让远程的浏览器全屏，Tab 留在远程的终端里。
